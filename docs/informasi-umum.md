# Informasi Umum (Profil Perusahaan)

> Lokasi menu: **Pengaturan → Profil Perusahaan → Informasi Umum** — URL `/profil/informasi-umum`

## Apa itu halaman ini?

Mengelola satu-satunya data profil perusahaan (nama, alamat, kontak, NPWP, logo) yang dipakai sebagai identitas perusahaan di cetakan/laporan.

## Cara mengisi

**Logo Perusahaan:** klik kotak upload untuk memilih file gambar (JPG/PNG, disarankan maksimal 2MB), preview langsung tampil.

**Detail Perusahaan:**
| Field | Wajib | Keterangan |
|---|---|---|
| Nama Perusahaan | Ya | |
| Alamat Lengkap | Tidak | |
| No. Telepon | Tidak | |
| Email | Tidak | |
| Website | Tidak | |
| NPWP | Tidak | |

Klik **"Simpan Perubahan"**.

## Terkait

- [Master Karyawan](master-karyawan.md) — data induk karyawan, di menu Pengaturan yang sama.
