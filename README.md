# 📊 Temui - Accounting Platform

Full-stack accounting system built with modern architecture using Golang, React, and PostgreSQL.

## 🚀 Tech Stack
- Golang (Gin)
- React
- PostgreSQL
- Wails (Desktop Packaging)

## ✨ Features
- Chart of Accounts (COA)
- General Ledger (GL)
- Trial Balance
- Financial Reports (Income Statement, Balance Sheet)
- Inventory, Sales, Purchasing
- Multi-client system (dynamic database switching)

## 🧠 Highlights
- End-to-end accounting system
- Multi-tenant architecture
- Desktop & web deployment
